# 워터마크 추적 실험 결과 (실측)

대상: `sample-game.js` (FallingDodge), 4층 워터마크, 페이로드 = 8비트 고객ID + 8비트 HMAC 태그.
도구: acorn(파싱), astring(생성), terser 5.51, javascript-obfuscator. Node 24.

## 1) 식별 정확도 (공격 없음)
- Publisher-A/B/C 모두 100% 정확 식별, 태그 검증 통과.

## 2) 공격 단계별 생존 (대상 Publisher-B, id=20)

| 공격 | L1 주석 | L2 함수순서 | L3 설정키 | L4 색상LSB | 판정 |
|---|---|---|---|---|---|
| A0 그대로 | ✓ | ✓ | ✓ | ✓ | **식별** |
| A1 주석·공백 제거 | ✗ | ✓ | ✓ | ✓ | **식별** |
| A2 terser minify+mangle | ✗ | ✗ | ✗ | ✓ | **식별** (L4 단독) |
| A3 beautify+수동편집(함수2개 이동+색상2개 변경) | ✗ | ✗* | ✗ | ✗* | 추적불가 |
| A4 강한 난독화 | ✗ | ✗ | ✗ | ✗ | 추적불가 |
| A5 처음부터 재작성 | - | - | - | - | 추적불가(정상) |

\* L2는 함수 1~2개만 옮겨도 순열 랭크 전체가 어긋나 붕괴. L4는 색상 2개 변경에 4비트 손상.

## 3) 오탐 검사
- 원본(무워터마크), 무관한 JS → 모두 "표식 없음"으로 정상 거부. **잘못된 지목 0건.**

## 핵심 결론
1. **RE 방지 효과 없음.** A4(난독화=RE 저항 도구)가 모든 층을 지웠고, 워터마크는 코드 열람·수정을 전혀 막지 못함.
2. **추적은 조건부로 유효.** 가볍게 재배포(주석제거·표준 minify)까지는 **확실히 추적**. L4(팔레트 LSB)가 표준 프로덕션 minify도 버티는 게 최대 강점.
3. **의도적 편집/난독화에는 추적 실패.** 하지만 **절대 오지목하지 않음**(태그 검증) → 책임 소재를 "잘못" 지울 위험은 없음.

## 개선 여지 (데모 강화용)
- L2: 전역 순열 랭크 → 인접쌍 비트 인코딩으로 바꾸면 함수 몇 개 이동에 graceful하게 버팀.
- L4: 색상 LSB에 오류정정부호(ECC) 추가 → 색 몇 개 바뀌어도 복원.
- 이러면 A3도 식별 가능해질 것으로 예상(미검증).
