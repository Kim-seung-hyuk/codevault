# REA_Defence 발표 근거 — Comet Shower 블라인드 복원

**발급 ZIP만 받은 AI가 Comet Shower를 재구현했다. Chrome에서 측정한 2,400프레임의 주요 게임 동작이 발급본과 일치했고, 복원 소스에서 협력사 ID 42가 검출됐다.**

## 슬라이드에 넣을 수치

| 지표 | 결과 |
|---|---|
| 게임 동작 | 동일 키 입력과 난수 시드 3개 × 800프레임. 점수, 목숨, 게임오버 표시, 우주선·혜성 위치 2,400/2,400 일치 |
| 핵심 데이터 | 혜성 위치·생성 간격 표의 정수 64/64 일치 |
| 소스 지문 | 복원본에서 L4·L8이 ID 42로 일치. L8 단독 검사도 ID 42 |
| 화면 지문 | L7은 발급본 PNG 3/3 검출, 복원본 PNG 0/3 검출 |

복원 세션에는 발급 ZIP과 독립 재구현 지시만 제공했다. 이전 대화, 고객사 원본 소스, 워터마크의 존재·위치, 평가 기준은 공유하지 않았다. AI는 픽셀 후처리를 생략했고, 게임 진행에 사용하는 혜성 데이터 표는 그대로 옮겼다.

## 발표에서 밝힐 검증 범위

게임 하나와 AI 복원 한 건의 관측 결과다. 2,400프레임은 복원본 하나를 시드 세 개로 재생한 분량이다. 워터마크 제거를 명시적으로 지시한 상황은 검증 범위 밖이다. ID 42는 발급 사본을 식별하는 데 쓰인다. 실제 유출자를 특정하려면 접근 기록 등 별도 증거가 필요하다.
